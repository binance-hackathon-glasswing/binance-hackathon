Collector implemented and pushed; 17/17 synthetic boundary tests pass. Signed development-host calls succeeded. Ten initial buy/sell quotes and ten matching unsigned approvals were collected across all five eligible tokens. Wallet API reports 100 USDT and no BNB entry. Every exact swap gas estimate failed before approval; no fallback is permitted. Router/selector are observed, but ABI, encoded expiry and canonical wallet nonce/finality remain unproved. **W08 is partially complete; live integration is blocked.** Exact artifacts, observed schema differences, owners and remaining gates are in EXP-005's results. Production-host behavior and registration/key binding were not established.

## Run

Commit and push changes before running, per AGENTS.md. Uses Python standard library; no new dependency or ai-seeds initialization. From the repository root:

```sh
python -m unittest discover -s tests -p 'test_w08_capabilities.py' -v
python tools/w08_capabilities.py --env-file .env
python tools/w08_capabilities.py --env-file .env --connectivity-only
```

Only `BINANCE_API_KEY`, `BINANCE_SECRET_KEY`, `AI_SEEDS_ADDRESS` are selected from the specified env file; environment values take precedence. The parser accepts literal values and rejects expansion. `--address` supplies a public wallet address; `--symbols NVDAB` narrows the investigation; `--amount-base-units` is the USDT input quote sample; repeated `--tx-hash` inspects existing public transactions, without creating any. Default sample is one USDT, not trade policy. `--connectivity-only` requires no wallet and collects just authentication/chain and token-metadata observations.

Network requests are limited to the read/build allowlist. Unsigned approve construction and gas-estimation POSTs cause no on-chain transaction. Redirects are refused. API requests are authenticated with the Web3 HMAC, which is distinct from signing a wallet transaction. The tool never loads wallet or ai-seeds signing credentials. Compliance, authentication and rate-limit errors stop collection; do not reroute around compliance restrictions. No automatic retries or nonce increments occur. A transport/auth/rate error is evidence of a blocked observation, not an unsupported chain capability.

Artifacts are content-addressed JSON in ignored `data/w08/`. The printed SHA-256 covers the complete artifact. Each response hash covers received bytes; stored JSON is parsed and credential-redacted, so it is not guaranteed byte-identical to the raw body. Non-JSON response bodies and exception strings are omitted. Records retain request parameters, timestamps, elapsed time, unsigned calldata, and response shape. Do not commit artifacts; preserve them securely for review and reference their hashes in EXP-005.

## W04 handoff requirements

| Capability | Evidence needed before execution relies on it |
|---|---|
| Route validation | Observed chain/router/selector → verified implementation/ABI → strict full economic decode. Unknown/nested route variants remain blocked. An API minimum alone cannot authorize a swap. |
| Approve | Exact canonical ERC20 approve bytes with spender equal to fresh swap router and exact requested amount. Collector checks only this calldata binding; W04 must additionally check token destination, chain, value, nonce, gas, intent and authorization. |
| Nonce | Wallet-wide canonical count plus pending/journal reconciliation, including approvals. Missing history and a timeout cannot release a nonce or reservation. |
| Finality | Receipt/transaction identity, canonical block hash, verified finalized head and reorg reconciliation. Indexed success/height remains provisional. |
| Quote expiry | Verified encoded deadline and any nested RFQ expiry semantics. Requote after approve; revalidate any changed bytes. Expiry does not prove an old swap never landed. |
| Gas | Exact unsigned payload estimate; distinguish absent allowance/balance from schema failure; checked integer padding, affordability and reserves in W04. Failed estimate blocks that execution; no fixed-450000 fallback. |
| Replacement | Disabled. Requires separate protocol evidence, authorization, retained attempt hashes, canonical winner reconciliation and tests before enabling. |

This collector deliberately reports every unknown swap as `signable=false`. It does not implement an ABI guess, canonical chain adapter, production authorization, durable journal, nonce allocator, replacement or live trading. Synthetic tests validate collector boundaries; only measured evidence can establish a venue capability. Keep GAP-29/31/41/47/49/52/65 open until the relevant implementation and integration evidence exist.
