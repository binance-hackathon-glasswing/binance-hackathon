## 1. Findings and recommended fixes

### Sampling unit and coverage
- **RT-01 (C) Rows exist only on filing days.** Many large moves have no own-firm filing (e.g. NVDA's 27 Jan 2025 DeepSeek drop; peer results, export rules, hyperscaler capex, macro). Exit decisions on held names also run on non-event days the model never saw, and V0 (D-07) then tests "evidence given an event happened", not "agent vs no-news agent". [E] only ~25–40% of large 5-session moves start near an own-firm material filing. **Fix:** base unit = **name × session panel** (every session, or every 5th session in 5 offset sub-panels); own-filing, peer, macro-calendar and GDELT fields are optional columns with an `is_event_row` flag. The event rows become a filter on the panel, and V0/V1 get matched rows by construction.
- **RT-02 (H) Most decision occasions in the scored run are not own-firm filings.** FOMC decides Oct 28 2026, the day before the run; Nov 3 is the US midterm; [E] only ~1–6 own-filing events for the five names fall inside Oct 29–Nov 12 (verify the 2026 earnings dates). **Fix:** linked-event features: peer earnings (8-K 2.02 / 6-K, incl. TSM monthly revenue) with the peer's day-0 abnormal return; point-in-time peer graph (top-10 trailing-250-day return correlates + same SIC, plus a hand list for the five); macro-calendar flags (FOMC, CPI, NFP, GDP/PCE, opex, index rebalances, elections, earnings season) as dates only.
- **RT-03 (M) Tier B has few names like the five.** Trees cannot extrapolate beyond the largest size bin; SKHY's nearest US lookalike is MU; 20-F filers (TSM, ASML) have no `EntityPublicFloat`. **Fix:** domain-classifier importance weights and a pre-registered "neighbour" slice (top ~30–50 by size in tech/semis) as a secondary population (see M5).
- **RT-04 (M) GDELT counts act as a firm ID and drift over time.** **Fix:** z-score counts per firm against its own trailing 60 days, normalise by total GKG rows, count unique domains, require an org-name match plus a business theme, treat missing files as NaN, end windows at t − 20 min by file timestamp, and audit entity precision on 100 hand-checked rows. Live must poll the same 15-minute files.
- **RT-05 (M) Choosing event types by price reaction is outcome selection.** **Fix:** run the materiality filter (M2) on 2018–2023 only, freeze the event-type list, never revisit it on later blocks.

### Point-in-time and leakage
- **RT-06 (C) Timezone and session-calendar errors can put entry before the event.** The submissions JSON `acceptanceDateTime` is true UTC; filing index pages show ET without a zone. A fixed UTC−5 conversion turns a 16:20 EDT release into 15:20, so entry = that day's close and the label contains the earnings gap; half-days (13:00 close) do the same. **Fix:** one tz-aware conversion to America/New_York; sessions and early closes from `exchange_calendars`; assert `entry_ts > t` on every row; unit test on NVDA accession 0001243821-26-000007 (JSON 21:15:34Z = 17:15:34 ET); leak canary: re-label with entry one session later — if the 2.02 edge collapses, suspect a timing leak.
- **RT-07 (C/H) Event merging and XBRL can bring post-t data into the state.** A merged cluster that keeps the first t but carries later items (10-Q on day 3) sees the future; `frames` returns the last-filed (restated) fact; the earnings exhibit (Ex-99.1) is generally not XBRL-tagged. **Fix:** a merged row's state includes only items with `source_ts ≤ t`; 8-K/A filings are their own events; per (concept, period) take the fact with max `filed` < date(t) from bulk `companyfacts`, never `frames`; G-05 assertion in the state builder.
- **RT-08 (H) Back-adjusted price levels encode future splits** (NVDA 2019 adjusted ≈ $3.4 vs ≈ $136 actual [E]), so a size feature built from them says "small → later UP". **Fix:** adjusted series only for returns; size = unadjusted close(t−1) × `dei:EntityCommonStockSharesOutstanding` from the latest filing before t; no price-level features.
- **RT-09 (H) Survivorship returns through the ticker/price join.** Current ticker files do not map dead CIKs; tickers change (FB→META). **Fix:** seed candidates from bulk `companyfacts` (all CIKs); map CIK → ticker by date from cover-page `dei:TradingSymbol` (2019+) plus a hand map for 2018; gate the price-join match rate ≥ 95% for delisted and active CIKs separately; delisting exit = last traded or cash-out price; D-09 must confirm delisted coverage in writing.
- **RT-10 (H) "Extractive" fields still leak if an LLM extracts them** (e.g. fills guidance direction from memory for 2018–23). **Fix:** every extracted value cites a verbatim span checked by string match, otherwise null; regex/table parsing first; one extractor code path for pre-cutoff, post-cutoff and live; compare null rates and value distributions pre- vs post-cutoff; run the name-the-firm probe on the extractor.
- **RT-11 (H) Retrieved article text can leak into the post-cutoff test.** Articles fetched now often append the reaction ("shares fell 8% after hours"). **Fix:** historical mode reads only the point-in-time store (EDGAR documents, Wayback snapshots dated ≤ t); strip sentences about the issuer's share price; log retrieval timestamps.
- **RT-12 (M) The encoder gate runs on a contaminated block.** ModernBERT-large was published 2024-12, so the 2024 calibration block is inside its pretraining window; Laya's cutoff is unknown. **Fix:** encoder gate and temperature on 2025-01+ only; no Laya evaluation until its cutoff is known; the GBM baseline is unaffected.
- **RT-13 (M) Train/serve timing skew.** Daily-bar event-day features include post-t data; the live token may fill earlier than the label's entry. **Fix:** pre-t features use bars to the previous close only; live execution follows the label's entry reference; record `first_public_ts` = min(acceptance, first GDELT firm mention) and flag rows lagging by > 1 session.
- **RT-14 (M) Embargo, float semantics, SIC, DART.** Purge on label end t1 (not t) at every block boundary; `EntityPublicFloat` is a Q2 value filed once a year (up to ~20 months stale): use it for membership with a 12-month buffer, query per CIK, join `filed` to acceptance time by accession; SIC codes are current-only (accept as static); DART dates may be date-only → t = next session.

### Labels and classification
- **RT-15 (C) A fixed ±100 bp cut makes P(UP) mostly a volatility proxy.** At zero drift, P(r₅ > 1%) ≈ 0.36 for a 1.2%-daily-vol utility vs ≈ 0.45 for TSLA [E], so the high-P(UP) tail selects noisy names; labels ignore magnitude; FLAT vs DOWN is the same action for a flat long-only book. **Fix:** vol-scaled target z = r / σ₅ with σ₅ = trailing 60-session daily vol × √5 known at t (same σ as I-61 sizing); model z by GBM regression or ordinal classes at |z| ≥ 0.5 (~31/38/31 for every name); apply the cost hurdle only at decision time (enter iff calibrated P(ẑ·σ₅ > c + b) ≥ θ) and in the metric, so relabelling is never needed when quote costs are measured.
- **RT-16 (C) Absolute labels teach market beta and the calibration year's drift, and collapse effective n.** Events in the same week share the market move, so n_eff for calibration is closer to the number of distinct weeks; temperature on 2024 (strong bull year) bakes in a bull base rate. **Fix (D-06):** market-relative label r_idio = r − β̂·r_SPY with β from 250 pre-t sessions (QQQ is the wrong benchmark for non-tech Tier B names); store r_abs and sector-ETF-relative too. Absolute exposure belongs to the regime governor (I-66). Decision: E[r_abs] = β·μ_mkt + E[r_idio] with μ_mkt = 0 or the regime-gated value, pre-registered.
- **RT-17 (H) The label measures post-announcement drift, which the literature finds near zero in large caps.** Most 2.02 filings are after the close, so next-open entry correctly excludes the gap — where most of the reaction is. LLM news predictability is mostly next-day and strongest in small stocks; no peer-reviewed evidence found that GDELT tone helps at 5 days in large caps. Expected H-02 result: null [INFERENCE]. **Fix:** pre-register that the hoped-for skill is selection (abstaining well), not drift; store r_gap (last close before t → entry open) as a diagnostic and as H-01's only realistic edge if off-hours orders are possible; keep GDELT counts and tone as controls.
- **RT-18 (M) Horizon vs scored window and exits.** The run is ~10 sessions; late entries are graded on fewer sessions; exits are not a 5-session time stop. **Fix:** store r₁, r₃, r₅, r₁₀ and choose h in train CV only; add an explicit time stop at h; no new entries in the last [3] sessions (G-24).
- **RT-19 (M) One temperature cannot calibrate the traded tail.** ±5 pp reliability at p ≈ 0.5 needs ~384 independent cases; the 2024 tail has ~100–200 effective after week clustering [E]. **Fix:** calibrate the traded quantity (binary P(ẑ·σ₅ > c + b)) with isotonic or Platt scaling; week-block bootstrap intervals; report calibration slope as well as ECE.
- **RT-20 (L) Path dependence.** Store maximum adverse excursion from daily lows; adopt triple-barrier labels only if a per-position stop is added to the policy.

### Evaluation, power and generalisation
- **RT-21 (C) V1 has no clean block to be fitted on.** Judgement fields exist only post-cutoff, so fitting or selecting them uses the "used once" test block. **Fix:** freeze V0 (extractive-only) before the cutoff; V1 = frozen V0 logit + at most 3 judgement-field coefficients and its own θ, fitted on the first half of the post-cutoff window (time-ordered), 5-session embargo, tested on the second half. Pre-register the split now. Alternative: judgement fields only as a fixed-rule veto (H-02 V2), with no fitting.
- **RT-22 (C) The final block is under-powered, and the D-08 ladder means the test barely changes what ships.** [E] 9-month window, 20% coverage, week-clustered: minimum detectable edge ≈ 128 bp with absolute labels, ≈ 79 bp with relative labels, against a plausible large-cap edge of ~10–40 bp after cost; the five-name slice has ~3–5 traded cases. Under D-08 "inconclusive" and "supported" both run V1. **Fix:** paired metric (V1 − V0 on the same cases; market term cancels; [E] MDE ≈ 56 bp); relative labels; smallest effect of interest [25] bp; decision rule on the point estimate plus top-bin reliability (e.g. full budget only if Δ̂ > 0 and reliability within ±10 pp; otherwise V0 or comparator C1); report n_eff and MDE.
- **RT-23 (H) Wrong or unstated resampling unit; n_eff is 3–6× below N.** **Fix:** moving-block bootstrap over calendar weeks (2-week blocks, longer than h); cross-check with two-way clustering by week and name; report the design effect. Purged CV stays right for fitting but does not fix inference.
- **RT-24 (H) The test depends on an unknown, possibly late LLM cutoff.** A 2026-era hosted model may leave ≤ 6 months; stated cutoffs are unreliable and snapshots change. **Fix:** decouple V0's generalisation test — rolling-origin walk-forward 2024-07 → 2026-09 (~27 months, [E] MDE ≈ 55 bp) — from the V1 increment; probe the effective cutoff (~20 closed-book monthly questions, 2024-01 → 2026-09; last month significantly above chance + 2 months margin); require an effective cutoff ≤ 2025-09 in D-03; pin the snapshot and re-probe on change.
- **RT-25 (H) The live run cannot validate the model, and no comparator is defined.** [E] ~1–2 catalysts in the window; 4 trades × 18 USDT × 50 bp ≈ +0.18% of equity vs ~1.5–2.5% exposure noise, so the score is mostly exposure × market path. **Fix:** pre-register comparators over all historical 10-session windows of the five underlyings (2018–2026) and in portfolio simulation: C0 cash; C1 regime-gated (I-66), vol-scaled equal-weight hold of the five at the same average gross; C2 20-day vol-scaled momentum. Judge LARP as an overlay on C1; add C1 to the D-08 ladder above cash.
- **RT-26 (M) Garden of forking paths.** [E] 3 h × 2 label types × 3 c + b × 3 models × 4 feature sets = 216 configurations; best-of-216 null z ≈ 3.3. **Fix:** trial register of every configuration evaluated on the threshold block; deflated Sharpe or t ≥ 3; coverage = top-k% per month by score (not a fixed θ); one-shot freeze: final-block labels encrypted, manifest (commit, weight SHA-256, config, metric script, bootstrap seed, decision rule) committed and pushed before decryption.
- **RT-27 (M) A pooled Tier B edge may come from mid-caps.** **Fix:** test the edge × log(size) interaction; ship only if the neighbour-slice point estimate is ≥ 0.
- **RT-28 (M) The basis gate has no metrics.** Token history since 2026-06-11 gives ~18 non-overlapping 5-session windows per name; `candles` returns only periods with trades (stale prices). **Fix:** align bars at 16:00 ET; per-name gate [E tolerances]: 5-session tracking-error std ≤ 150 bp, token-on-share β in [0.9, 1.1], |mean premium| ≤ 25 bp, premium std at entry ≤ 50 bp, class agreement ≥ 85–90%, Multiplier events reconciled. A name that fails is risk-governor-only.
- **RT-29 (L) The dev forward test is a tripwire, not a calibration.** Freeze by Oct 18, hash-log daily Tier B shadow predictions from Oct 19: train/serve feature parity ≥ 99%, top-bin realised rate within ±20 pp, basis tracking. Never tune on it (G-46).

## 2. "Well captured": dataset acceptance gates
A "move" = a non-overlapping per-name 5-session market-relative return with |z| > 2 (σ₅ known at t). All thresholds are [E]: pilot them on 2018–2023, freeze them in this entry, then open later blocks. Dataset accepted = M1–M7 pass on the blocks they apply to; any failure becomes a GAP item and a version event. Never lower a threshold after seeing a later block.

| # | Metric | How computed | Gate | Why |
|---|---|---|---|---|
| M1 | Move recall | Share of moves with ≥ 1 dataset signal within [−1, 0] sessions of the move's start (own filing, peer event, macro release, GDELT z > 3, scheduled company event); filing-only rate reported alongside | ≥ 65% Tier B, ≥ 60% for the five (full sources) | The sources can see what drives moves; 100% is not the target (much stays unexplained) |
| M2 | Event materiality | Per event type: day-0/1 abnormal variance on event rows ÷ the same name's non-event variance; train block only | ratio ≥ 1.5, bootstrap CI lower bound > 1.2 | Drops boilerplate items that add noise |
| M3 | Regime and state coverage | Cells = rule regime (I-66: market vol tercile × trend sign) × earnings season × FOMC/CPI/election week; adversarial-validation AUC separating test or live-like rows from the calibration block | ≥ 200 rows per cell in train, ≥ 50 in calibration and threshold; the run's cell covered; AUC ≤ 0.70 | Calibration only holds in states it has seen |
| M4 | Feature coverage parity | Missing rate per feature by block and slice (Tier B / neighbour / five) | gap ≤ 10 pp; required features ≤ 5% missing | Catches silent gaps (SKHY's Korean disclosures, GDELT density) |
| M5 | Transfer gap | Domain classifier P(five-like \| size, sector, β, vol, attention); neighbour slice = top decile; weights p/(1 − p) clipped at 10; leave-five-out scoring of their 2018–2024 rows | neighbour log-loss ≤ rest + 0.01; top-decile ECE ≤ 3 pp; Kish ESS ≥ 30% of n | Tests whether what Tier B learns holds for names like the five |
| M6 | Label stability | Share of rows changing class when c + b moves ±25 bp or entry shifts one session | ≤ 20%, reported by vol decile | How much of each label is noise |
| M7 | Token vs share basis | RT-28 metrics on bStock `candles` | RT-28 tolerances per name | The model trains on shares and trades tokens |

Model-level checks (not dataset gates), reported on Tier B, the neighbour slice and the five: weekly cross-sectional rank IC of ẑ vs realised z with a t-stat across weeks; after-cost mean excess return of the top coverage bucket; calibration slope of predicted vs realised (week-block bootstrap CI).

## 3. Recommended spec if every fix is adopted (for the team to accept or amend)
- Rows: name × session panel over Tier B + the five (+ peer ADRs as event sources only); event rows flagged.
- Label: r_idio = r − β̂·r_SPY over h = 5 (also store r_abs, sector-relative, r₁/r₃/r₁₀, r_gap, MAE); target z = r_idio / σ₅; c + b applied at decision time and in the metric only.
- Model: GBM regression or ordinal classes on z; encoder only if it beats GBM on 2025-01+ data.
- Splits: as in D-10 (a), with purging on label end; V0 test = rolling origin 2024-07 → 2026-09; V1 increment fit/test split inside the post-cutoff window.
- Inference: paired V1 − V0, week-block bootstrap, n_eff and MDE reported, smallest effect of interest [25] bp, comparators C0/C1/C2.
