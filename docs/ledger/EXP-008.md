# EXP-008 — Does S1 earn more than the equal-weight fallback over a 10-session run?

- Date / owner: 2026-10-23 / Keith (requested in session); criteria drafted with Claude
- Status: criteria written 2026-10-23 **before any data was fetched or any run**; **run 2026-10-23 at 301ba6c2:
  EW better for profit** (P, 25 bp). This is
  exploratory evidence for the team. It does not change PF-01 / IDEA-084 (S1 chosen), the SJ-09 swap plan or
  any profile, and it does not replace EXP-007.
- From: PR133 "Next: S1" (SJ-09) and the user's question whether S1 is better for maximising profit. The score
  is the wallet's % return over the scored run (F-43, F-46), so the measure is net return.
- Hypothesis: over 10-session windows, S1 `TREND_GUARDED_VOL` (IDEA-075) has a higher mean net return than
  EQUAL_WEIGHT (IDEA-037 / LD11-RH01).

## Variants (both arms: 200 USDT start, flat at the window end)

- **S1:** weights wᵢ ∝ 1/σᵢ (σ = SD of session log returns over the last 60 sessions **before** the window, at
  least 20; a name with fewer takes the median σ of the others), cap 0.30 with the excess spread pro rata
  (IDEA-075 §5.1, point in time as EXP-007 TRV-03). Target gross = trend level: basket index of equal-weight
  session returns, r = Iₜ ÷ mean(last 5 Iₜ) − 1, UP if r > +1 %, DOWN if r < −1 %, else unchanged; UP → 95 %,
  DOWN → 60 %. The state at the window start is run forward over all earlier sessions, starting UP. Level change →
  every name to its new target. Top-up when gross < target − 5 pp (names below target). Hard name line 35 % →
  back to target. No sale on drift.
- **EW (primary):** four names at 20 % (80 % gross), dropping MSFTB as the name with the highest measured
  round-trip cost (IDEA-063 C3, 17 bp off-session; the planner ranks entries by cost). Top-up when gross < 75 %
  (names below 20 % back to 20 %). Hard lines: a name > 25 % back to 20 %; gross > 90 % scaled back to 80 %.
- **Both arms:** the declared ladder on session closes (IDEA-075 §4.3): daily loss ≥ 3 % → no buys the next
  session; drawdown ≥ 8 % from the window's equity peak → no buys; ≥ 12 % → cut to 40 % gross. No limiter, no red
  flags, no minimum trade. A signal at close t trades at close t + 1 (daily data has no intraday bar); the
  opening buys trade at the first session close of the window.
- **Reported only, not used for the decision:** S1-STATIC (S1 weights, fixed 95 %, no trend guard) and EW5
  (five names at 16 %), to split the S1 − EW gap into gross level, weights and the trend guard.

## Data

- **Primary (P):** daily closes, split-adjusted, from Yahoo Finance's public chart endpoint, for NVDA, GOOGL,
  TSLA, MSFT (USD) and SK hynix 000660.KS (KRW; the latest KRX close on or before each US session date, FX
  ignored) as proxies for NVDAB, GOOGLB, TSLAB, MSFTB and SKHYB. US sessions from 2019-01-02 to the
  2026-10-22 close. Snapshot saved outside Git (`data/`, git-ignored) with its SHA-256 recorded below before the run.
- **Token check (T):** kit token 1-hour candles (`candles`, `after=` paging, participant-kit.md K6) for the five
  bStocks, session close = the last 1-hour bar that ends at or before 16:00 ET, up to the 2026-10-22 close. Same
  rules; reported as a consistency check only (the history is too short to decide anything).
- Windows: every overlapping 10-session window with at least 20 earlier sessions for σ.

## Costs

Traded notional × 25 bp per side plus 0.03 USDT gas per swap (as EXP-007). Sensitivity: 50 bp per side.

## Metrics

Per window: net return including the final flatten, maximum drawdown on closes, whether it reached 8 %. Mean,
median, SD, share of windows with return > 0. For S1 − EW: the mean difference with a moving-block bootstrap
90 % interval (block = 10 sessions, 10,000 resamples, seed 8). Also by calendar year.

## Pass criterion (P data, 25 bp)

- **S1 better for profit** if the mean S1 − EW net return > 0 AND the bootstrap 90 % lower bound > 0;
- **EW better for profit** if the bootstrap 90 % upper bound < 0;
- **no detectable difference** otherwise.

T is reported beside it (sign of its mean difference) and cannot change the outcome.

## Decision use

None automatic. The result is input for Keith / Keegan / Yao on SJ-09 and the scored-run profile. S1 is already
the team's chosen strategy (IDEA-084); a "no detectable difference" or "EW better" result is a reason to discuss
it, not to change a profile.

## Caveats (written before the run)

- Underlying stock closes are a proxy: the tokens trade 24/7 and can drift from the underlying off hours
  (IDEA-012); SK hynix is in KRW on another exchange.
- 2019–2026 is mostly a rising market for these five names. Higher gross (95 % vs 80 %) wins in rising markets by
  construction, so a positive S1 − EW mean may mostly reflect that.
- Overlapping windows are not independent; the block bootstrap only partly allows for that.
- Simulated at close prices, not realised fills (ledger rule 4).

- Code / config: `tools/exp008/fetch.py` (snapshot) and `tools/exp008/simulate.py` (SHA-256 `1dcacf63462964a5c8e149ad1128ff3f87e0b1e030353fcedda8db6b7ef34d17`),
  committed before the run; checked first on synthetic flat/up/down prices (flat-market costs match the hand
  calculation: EW −0.52 %, S1 −0.625 % at 25 bp).
- Data snapshot SHA-256 (fetched 2026-10-23 after the pre-registration commit 7c87b8e2, before any run):
  `data/exp008/underlying.json` `f061394d5f5804267324080a1818538e9dff16b815bfa5faa7530e5df53a39b4`;
  `data/exp008/tokens.json` `8949348ebf99946a3be82113e2fe2808ed840c315a25f9597d3283952fd96e4a`.

- Result (run 2026-10-23, commit 301ba6c2, report kept at `data/exp008/report.json`, git-ignored):

  | 10-session windows | S1 | EW | S1 − EW (90 % CI) | S1 ahead |
  |---|---|---|---|---|
  | **P 25 bp** (1,954 windows, 195 non-overlapping, 2019-01-02 → 2026-10-22) | +0.34 % mean, SD 4.1 %, P(DD ≥ 8 %) 3.5 % | +0.92 %, SD 5.2 %, 9.7 % | **−0.58 pp (−0.77, −0.41)** | 36 % |
  | P 50 bp | −0.16 % | +0.52 % | −0.68 pp (−0.87, −0.51) | 34 % |

  **Outcome (pre-registered rule): EW better for profit.** S1 − EW is negative in every calendar year (2019 −0.31,
  2020 −1.42, 2021 −0.20, 2022 −0.00, 2023 −0.54, 2024 −0.76, 2025 −0.76, 2026 −0.64 pp). T agrees in sign and
  cannot decide anything on its own. MSFTB had two carried-forward token closes.

  Decomposition (P, 25 bp, reported only): S1-STATIC − EW −0.24 pp (weights and name set, net of the +15 pp of
  gross); S1 − S1-STATIC −0.33 pp (the trend guard); EW5 − EW −0.18 pp. On T the static S1 book led EW by +0.48 pp
  and the guard cost −0.50 pp.

  Diagnostic, run after the result (exploratory, not part of the rule): mean S1 weights NVDAB 0.16, GOOGLB 0.25,
  SKHYB 0.19, TSLAB 0.13, MSFTB 0.27, while mean 10-session returns were NVDAB 2.30 %, TSLAB 2.06 %, SKHYB
  1.84 %, GOOGLB 1.00 %, MSFTB 0.88 %. Inverse-σ weighting moved money from the three highest-return names into the
  two lowest, and EW's cost rule happened to drop the lowest-return name. The trend state was DOWN (60 %) on 37 %
  of sessions with about 35 flips a year: the guard mostly whipsaws in this sample.

  Reading: the five names were picked as bStocks after a period in which their most volatile members rose most,
  so this sample rewards a high-vol tilt; that need not repeat in the scored run. The gap (about 0.6 pp, ≈ 1.2 USDT
  on 200 USDT per window) is small next to the window SD (4–5 %), and S1 roughly halved P(DD ≥ 8 %). It is evidence
  for a team discussion of S1's weights and trend guard on profit grounds, not a profile change.

## Review notes (2026-10-23, Keegan's session, at merge)

- **The recommendation is a judgement against the pre-registered outcome.** The pre-registered rule gives **EW
  better for profit**: the 90 % interval lies wholly below zero, and S1 is behind in every calendar year. Keeping S1
  is allowed, because the decision rule was "none automatic". But the "hindsight" reading and the weights diagnostic
  were written after the result; only the rising-market caveat was written before it, and that caveat favoured S1.
  The honest summary is therefore: *the test favoured EW; the team keeps S1 for lower drawdown (3.5 % vs 9.7 % of
  windows reaching the 8 % stop) and to avoid reopening profile, coverage and release checks before Oct 29.*
